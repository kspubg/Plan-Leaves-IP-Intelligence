## 安装与数据保留

先停服，备份 `plugins/Plan/`、原插件 JAR、`banned-players.json` 和 `banned-ips.json`，再替换单个 Plan JAR。不要保留两个 Plan JAR，也不要删除数据库来升级。

保留现有 config.yml、database.db（或 MySQL）、ServerInfoFile.yml、IP 离线库、网页账号及个性化配置。新功能配置与授权步骤见 [处置与登录说明](IP-MODERATION.zh-CN.md)。LuckPerms 游戏权限不能替代 Plan 网页用户组权限。

旧 public_html 中的 React bundle 可能覆盖新界面，应先备份并逐项确认旧覆盖；不要用旧版 public_html 重新覆盖新版前端，也不要删除整个 Plan 数据目录。

`ip-moderation.json` 保存独立审计、撤销和观察数据，必须随同实例备份；它不会由 `/plan db move` 迁移。原生封禁名单也应一起保留。

本次选择继续使用现有 HTTP 配置，没有启用 HTTPS、申请证书或新增 HTTPS 强制/禁止降级逻辑。HTTP 上密码、会话和 IP 数据仍为明文；登录、权限与 CSRF 不能替代传输加密。不要把明文面板暴露在不可信网络，建议使用 VPN、SSH 隧道或可信管理网络。公版默认配置不包含正式服地址、密码或玩家数据。
